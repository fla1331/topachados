================================================================
📝 COMO FUNCIONAM OS TEMPLATES (.txt)
================================================================

PASTA: templates/
TEM 5 ARQUIVOS:

1. review.txt → Molde para REVIEWS
   Contém estrutura: Introdução → Especificações → Conclusão

2. guia.txt → Molde para GUIAS  
   Contém: O que é → Como escolher → Dicas

3. preland.txt → Molde para PRE-LANDING
   Contém: Problema → Solução → Benefícios → Oferta

4. comparativo.txt → Para comparações
5. analise.txt → Para análises técnicas

COMO EDITAR OS TEMPLATES:
1. Abra o arquivo .txt
2. Mude o texto mantendo os {NOMES} entre chaves
3. Salve

EXEMPLO NO review.txt:

PRODUTO: {PRODUTO} ← NÃO MUDE ISSO
CATEGORIA: {CATEGORIA} ← NÃO MUDE ISSO
IDIOMA: {IDIOMA} ← NÃO MUDE ISSO



O sistema substitui automaticamente:
{PRODUTO} → "Resveratrol Premium"
{CATEGORIA} → "suplementos"
{IDIOMA} → "português"

================================================================
📊 ARQUIVO produtos.csv - COMO USAR
================================================================

Crie um arquivo chamado produtos.csv (Excel/Bloco de Notas)

FORMATO:
produto,idioma,categoria,tipo_artigo,site_oficial,links_afiliados,status
Resveratrol,pt-BR,suplementos,review,https://site.com/,https://afiliado.com/,pending
Resveratrol,pt-BR,suplementos,preland,https://site.com/,https://afiliado.com/,pending
Meditação,en-US,mente,guia,https://site.com/,https://afiliado.com/,pending

EXPLICAÇÃO SIMPLES:
- produto: Nome do produto
- idioma: pt-BR (português), en-US (inglês)
- categoria: suplementos, fitness, mente (crie as suas)
- tipo_artigo: review (análise) ou preland (problema→solução)
- site_oficial: URL do fabricante
- links_afiliados: SEU link de afiliado
- status: pending (não feito) → completed (feito automático)

================================================================
🔄 SISTEMA DE FUNNEL (2 ARTIGOS POR PRODUTO)
================================================================

QUANDO tipo_artigo = "preland", cria:

📝 ARTIGO 1: REVIEW TÉCNICO
URL: suplementos/resveratrol/
CONTÉUDO: Análise técnica, estudos, especificações

🎯 ARTIGO 2: PRE-LANDING (GUIÁ)
URL: suplementos/resveratrol-guia-completo/
CONTÉUDO: Foca em PROBLEMA → SOLUÇÃO
EXEMPLO:
- PROBLEMA: "Envelhecimento precoce, falta de energia"
- SOLUÇÃO: "Resveratrol pode ajudar"
- NÃO É sobre o produto, é sobre a DOR do cliente
